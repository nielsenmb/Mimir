Mimir
=====

Mimir is a shared time-series and power-spectrum package for PBjam, Skuld,
Urdr, and related asteroseismology projects.

The scientific API is under development. Time-series validation,
nifty-ls power-spectrum calculation, and optional Lightkurve-based MAST access
are available.
