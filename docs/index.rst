Mimir
=====

Mimir is a shared time-series and power-spectrum package for PBjam, Skuld,
Urdr, and related asteroseismology projects.

The scientific API is under development. Time-series validation is now
available, while spectrum calculation and archive access will be introduced in
separate, independently reviewed stages.
