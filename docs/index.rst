Mimir
=====

Mimir is a shared time-series and power-spectrum package for PBjam, Skuld,
Urdr, and related asteroseismology projects.

The scientific API is under development. Time-series validation and
nifty-ls power-spectrum calculation are available, while archive access will
be introduced in a separate, independently reviewed stage.
