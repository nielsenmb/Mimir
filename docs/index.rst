Mimir
=====

Mimir is a shared time-series and power-spectrum package for PBjam, Skuld,
Urdr, and related asteroseismology projects.

The scientific API is under development. This initial documentation records
the intended boundaries so that compatibility and numerical changes can be
reviewed separately.
